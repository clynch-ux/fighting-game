# Pixel Clash

A lightweight browser fighting game built with HTML, CSS, and JavaScript.

## How to play

Open `index.html` in a browser.

- Player 1: A / D to move, W to jump, F to attack
- Player 2: Left / Right to move, Up to jump, `/` to attack

## Goal

Reduce your opponent's health to zero before the timer reaches zero.

## Files

- `index.html` – game structure
- `style.css` – arena and HUD styling
- `script.js` – game loop, movement, combat, and AI

## Notes

This is a simple local 2D fighting game prototype, designed to be easy to extend with extra moves, sound, or character selection.
